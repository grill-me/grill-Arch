# Arch 是什么

## 类别 + 类比

**类别**：滚动发行版（rolling release）通用 Linux 发行版，x86_64。

**类比**：

| 类型 | 代表 | 模型 |
|---|---|---|
| 固定发行版 | Ubuntu 24.04、Debian 12 | 软件超市：预装好货架，升级要换货架（版本号跳跃） |
| **滚动发行版** | **Arch**、Manjaro | 自己进货的仓库：直接拉最新件，永远只有一个版本在跑 |

## 核心哲学三原则

| 原则 | 意思 | 对你的实际影响 |
|---|---|---|
| **KISS**（Keep It Simple, Stupid） | 一个功能只用一种方式实现，不搞多套并行工具 | 装完几乎全空：没有默认桌面、没有预装服务，一切自己选 |
| **Simplicity**（简洁） | 只装需要的，不装不需要的 | 系统干净，知道每个包为什么在 |
| **Userland**（用户空间） | 配置是文本文件，`/etc` 里自己改 | 所有东西可追溯、可脚本化，上手门槛在这里 |

## 和 Windows / Ubuntu 的核心差异

- **Arch 装完就是个带 shell 的空盒子**——没有桌面、没有网卡驱动以外的东西
- 你要么在终端里装桌面，要么就用它当纯命令行/开发机
- 这个"空"是特性不是 bug

## 系统要求

- 任意 x86_64 机器
- 最低 512 MiB RAM（实际装机建议 4G+）
- 基础安装 < 2 GiB 磁盘
- 网络（装机时要从仓库拉包）

## 当前版本（2026-10）

- 镜像：`archlinux-2026.10.01-x86_64.iso`（1.5GB）
- 内核：7.2.7
- 不支持 Secure Boot（装机时要在 BIOS 里关掉）
